# Kwench

Chat with the KWENCH bot to manage workspace bookings directly from Raycast.

## Features

- Book meeting rooms, phone booths, and resident booths
- Check availability of workspace resources
- List your existing bookings
- Cancel reservations

## Setup

1. Get your API key by running `apikey` in Slack
2. Open Raycast Preferences > Extensions > Kwench
3. Enter your API key

## Requirements

- KWENCH API key (obtained via Slack)
