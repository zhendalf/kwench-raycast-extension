# Kwench

Chat with the KWENCH bot to manage workspace bookings directly from Raycast.

## Features

- Book meeting rooms, phone booths, and resident booths
- Check availability of workspace resources
- List your existing bookings
- Cancel reservations

## Usage

### AI Chat (Recommended)

Open Raycast AI Chat and type `@kwench` followed by your request:

- `@kwench book a meeting room tomorrow at 2pm`
- `@kwench what rooms are available this afternoon?`
- `@kwench show my bookings`
- `@kwench cancel my booking tomorrow`

### Quick AI

Open Quick AI and mention `@kwench` with your request.

### List View

Use the "Ask KWENCH" command for a traditional list-based interface with conversation history.

## Setup

1. Get your API key by running `/apikey` in Slack
2. Open Raycast Preferences > Extensions > Kwench
3. Enter your API key

## Requirements

- Raycast Pro subscription (required for AI features)
- KWENCH API key (obtained via Slack)
